# ZAIN INDUSTRIES project images

Upload the main project logo or cover directly inside this folder.

Upload building images into the dedicated folders:

- `building-01/`
- `building-02/`
- `building-03/`

For additional buildings, continue with `building-04/`, `building-05/`, and so on.

Once images are uploaded, the folders can be renamed to the real building names and the image files can be normalized to a clean sequence such as `building-name-01.jpg`, `building-name-02.jpg`, etc.
