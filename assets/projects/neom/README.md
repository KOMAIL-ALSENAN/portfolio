# NEOM Project Images

Upload project images into one folder per building:

- `building-01/`
- `building-02/`
- `building-03/`

For additional buildings, create folders using the same pattern, for example `building-04/`, `building-05/`, etc.

Recommended image naming:

- `01.jpg`
- `02.jpg`
- `03.jpg`

A project logo/cover can be uploaded directly under `assets/projects/neom/` and named `neom-logo.png` or `neom-cover.jpg`.
