Requirementsمتطلبات التشغيل

What you need.ما تحتاجه للتشغيل.

Standard requirementsالمتطلبات الأساسية

Windows 10/11 and Python 3. The application uses Tkinter, PyMuPDF and Pillow. The portfolio build can install PyMuPDF and Pillow locally on first run when internet access is available, without requiring administrator rights.Windows 10/11 وPython 3. يستخدم التطبيق Tkinter وPyMuPDF وPillow. نسخة البورتفوليو تستطيع تثبيت PyMuPDF وPillow محليًا عند التشغيل الأول عند توفر الإنترنت، دون الحاجة إلى صلاحيات Administrator.

Optional OCR requirementمتطلب OCR الاختياري

Tesseract OCR is only required for the OCR feature. The rest of PDF Toolbox works without Tesseract.Tesseract OCR مطلوب فقط لميزة OCR. بقية أدوات PDF Toolbox تعمل بدونه.

Runطريقة التشغيل

How to run PDF Toolbox.طريقة تشغيل PDF Toolbox.

Download and extract the packageحمّل الحزمة وفك الضغطKeep the application files together in one folder.احتفظ بملفات التطبيق معًا داخل مجلد واحد.
Open the folder in VS Codeافتح المجلد في VS CodeMake sure Python 3 is available on the workstation.تأكد من توفر Python 3 على الجهاز.
Run main.pyشغّل main.pyUse Run Without Debugging (Ctrl+F5), or run python main.py from the terminal.استخدم Run Without Debugging ‏(Ctrl+F5) أو نفّذ python main.py من الطرفية.
First-run setupإعداد التشغيل الأولIf PyMuPDF or Pillow are missing, the application installs them beside the tool on first run. Internet access is needed only for that setup.إذا لم تكن PyMuPDF أو Pillow موجودة، يقوم التطبيق بتثبيتها بجانب الأداة في أول تشغيل. الإنترنت مطلوب فقط لهذه الخطوة.
