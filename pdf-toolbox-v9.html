About

One toolbox for engineering PDF workflows.

PDF Toolbox V9 brings common engineering-document tasks into one desktop application instead of relying on multiple separate utilities.

▦

PDF & Page Tools

Crop, merge, split, extract, rotate, reorder, resize and convert PDF pages.

⌁

Engineering Workflows

Batch conversion, sheet numbering, drawing register, drawing-set merge and drawing audit tools.

✓

Quality & Management

Health checks, exact duplicate detection, project profiles, activity log and metadata utilities.

◫

PDF ↔ Images

Convert PDF pages to images, create PDFs from images, extract embedded images and build contact sheets.

◎

Arabic / English

Bilingual application interface with built-in help for the individual tools.

⌕

Optional OCR

Extract text from scanned PDF pages when Tesseract OCR is installed on the workstation.

Requirements

What you need

  • Windows 10 or Windows 11.
  • Python 3.10+ recommended.
  • Internet connection for the first run if PyMuPDF and Pillow are not already available. The tool installs them locally beside the app; Administrator rights are not required.
  • VS Code is recommended for the portfolio/source release.
  • Tesseract OCR is optional and required only for the OCR module.
Run guide

How to run PDF Toolbox

  1. Download and extract the ZIP package.
  2. Open the extracted folder in VS Code.
  3. Make sure Python is selected as the interpreter.
  4. Open main.py and press Ctrl+F5 (Run Without Debugging).
  5. On first run, allow the local dependency setup to finish. Then the application opens normally.
python main.py
